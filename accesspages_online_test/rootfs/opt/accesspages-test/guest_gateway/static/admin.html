Security reset

Reset OpenNHP Service connection?

This action will:

  • Immediately revoke every existing guest and access link.
  • Attempt to remove the old AccessLinks from OpenNHP Service.
  • Remove this connector's credential, identity, and state.
  • Preserve all page names, descriptions, entities, and actions.

You will reconnect with an API key and create new guest links. This cannot restore the old guests.
